Project 01

Security risk in 28M+ app reviews

RoBERTaZero-shotPythonStatistics
Problem

App store reviews contain security signals that cannot be read manually at this scale and language diversity.

Approach

Fine-tuned RoBERTa across 1,567 apps, added zero-shot learning for 10+ South Asian languages and compared app tiers with confidence intervals.

94.8% accuracy, 0.955 F1. Top-grossing apps are flagged at twice the rate of top-paid apps (2.9% vs. 1.4%).
Project 02 · Patent

Tamper-aware authentication on FPGA

Logic lockingAESCVivado HLS
Problem

Logic-locked hardware needs secure key authentication and detection of unauthorized access.

Approach

UART protocol in C, AES core via HLS and an HC-05 Bluetooth alert on wrong-key entry, on a Zynq FPGA.

408-cycle latency, 1.714 W. Patent No. 202541088733. IEEE Best Paper, sole author.
Project 03

Defenses prioritised by return

Threat modellingAMC framework
Problem

Where should limited engineering effort go to block the most hardware attacks?

Approach

Mapped the attack surface of 15+ patents (physical and reverse-engineering vectors) and scored cost-per-ROI per attack vector with the AMC framework.

A ranked defense report directing investment to the highest-impact countermeasures.
